# Структура проекта

### Директория *tests*
Основа проекта - здесь хранятся тесты.

### Директория *config*
Здесь хранятся конфигурационные настройки (например, базовые урлы разных API).

### Директория *data*
Тестовые данные для проверок.

### Директория *fixtures*
Здесь лежат фикстуры.

### Директория *helpers*
Помощники :)

### Директория *schemas*
json-файлы, содержащие схемы ответов.

### Файл *conftest*
Модуль для фикстур, хуков и пр.

### Файл *pytest.ini*
Файл с пользовательскими pytest.mark

### Файл *.env.example*
Здесь храним секьюрные данные (например, токен).

Не пушим! В удаленном репозитории будет всегда лежать .env.example для ввода своих данных.
